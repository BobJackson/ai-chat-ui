# AI Chat UI (Next.js 16)

A minimal streaming chat UI built with Next.js 16.

## Dev

```bash
pnpm i # or npm i / yarn
pnpm dev
```

Open `http://localhost:3000`.

## Files
- `app/page.tsx`: chat UI with streaming client
- `app/api/chat/route.ts`: demo streaming API (edge runtime)
- `app/globals.css`: minimal styles
